등산여지도 — PC 미리보기 (최종 · 전국 타일·코스 적용)

실제 앱과 같은 코드가 모바일 화면 크기로 동작합니다 · 브라우저에서 위치 권한을 허용하면 PC 위치 기준으로 표시됩니다

테스트 순서
1. 닉네임 입력 → 시작 → [위치 권한 허용하기] (브라우저 팝업 허용)
2. 홈: 반경·해발 필터, 거리순/난이도순
3. 산 찾기: "금정산", "천왕봉" 검색 / 지역 버튼
4. 산 상세: 지도에 코스 번호 선 여러 개 → 선 또는 카드 탭 → [내비 안내] / [이 코스로 기록 시작] (확인 창)
5. 기록: [시작] → [휴식]/[등산] → [하산 시작] → [화면 잠금] → [종료] → 결과·요약 카드·칼로리 환산
6. 산 찾기: "지리산" 검색 → 산군 묶음 / [100대 명산] 탭 / ★ 즐겨찾기
7. 산 상세: 날씨·일출몰, [오프라인 지도 저장], [현장 정보] 탭, 🚌 대중교통, 🔗 코스 공유
8. 친구: [동행] 위치 공유, [모임] 등록·참여 / 마이: 안전 연락처, 다크 모드·큰 글씨, 📊 리포트 / 상단 SOS
PC에서는 GPS가 움직이지 않아 거리·칼로리는 0에 가깝습니다. 백그라운드 기록·기압계·진동·내비 앱 열기·연락처는 휴대폰 앱에서만 동작합니다. 지도 데이터는 산을 처음 열 때 인터넷에서 받아옵니다(10~30초).
